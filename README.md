# ZARMEEN — Wear Your Heritage
### Luxury Pakistani Women's Clothing E-Commerce House & Unified Atelier Suite

**ZARMEEN** is a production-grade, high-fashion Pakistani women's clothing e-commerce web application designed for a luxury fashion house. It combines centuries of South Asian heritage needlecraft—Pima lawn, handwoven raw silk, organza, zardozi, tilla, and mirror embellishments—with modern e-commerce capabilities.

---

## 🌟 Key Features

### 🛍️ Customer Boutique
- **Curated Collections & Lines**:
  - Unstitched Lawn (3-Piece, Schiffli, Silk Dupattas)
  - Ready to Wear Pret & Co-ords
  - Luxury Raw Silk Handcrafted Pret
  - Festive & Formal Chiffon Pishwas / Kalidaars
  - Bridal & Wedding Edit (Ghararas, Jamawar)
  - **ZARMEEN MODEST**: Korean Crepe Abayas & Draped Hijabs
- **Interactive Multi-Filter Shop**: Filter by Category, Collection, Fabric, Size, Color Tone, and Price Range in **PKR**.
- **Product Details & Media**:
  - Multi-angle visual gallery with click-to-zoom
  - Embedded HD video player with custom play/pause/mute controls
  - Real Pakistani garment specifications (Shirt, Trouser, Dupatta fabric lengths)
  - **Pakistani Size Chart Modal**: Garment measurements in both inches and cm
- **Shopping Bag & Express Shipping**:
  - Slide-out bag drawer with quantity adjustments
  - Free Delivery Progress Bar (Complimentary express delivery on orders above PKR 5,000)
- **Nationwide Pakistani Checkout**:
  - Full address system supporting all Pakistani cities (Lahore, Karachi, Islamabad, Rawalpindi, Peshawar, Multan, Quetta, etc.) and provinces
  - **Cash on Delivery (COD)**, Direct Bank Transfer (Meezan Bank Islamic IBAN), and Debit/Credit Card
- **Order Tracking & Invoices**:
  - 7-stage shipment tracker (`Order Placed` → `Confirmed` → `Processing` → `Packed` → `Shipped` → `Out for Delivery` → `Delivered`)
  - Professional, printable and downloadable digital invoices with Zarmeen branding & NTN
- **Customer Account Portal**: Order history, saved delivery addresses (add/edit/delete), and wishlist.

---

### 👑 Unified Atelier Admin Suite
- **Product Management (Add / Edit / Remove Clothes)**:
  - Add new garments with title, SKU, category, collection, fabric, stitched/unstitched, pieces, prices in PKR, stock, sizes, and colors.
  - Multi-image gallery manager with local upload, URL input, and "Make Main" display selector.
  - Activate / Deactivate (Hide/Show) garments from the public storefront with one click.
  - Safe deletion with confirmation modal (preserves historical order records).
- **Categories & Collections Management**: Add, edit, delete, and toggle categories and seasonal couture edits.
- **Order Fulfillment & Logistics**: Update tracking status, confirm payments, view customer addresses, and print order invoices.
- **Coupons & Promotions**: Create percentage or fixed PKR discounts with minimum order thresholds (e.g. `ZARMEEN10`, `EID2026`).
- **Review Moderation**: Approve, reject, or delete customer reviews before they appear publicly.
- **Sales Analytics & KPIs**: Real-time gross revenue in PKR, order counts, and weekly sales volume charts.

## 🛠️ Tech Stack

- **Frontend & App Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Custom Luxury Serif & Sans Typography
- **Icons & Motion**: Lucide React, Motion
- **State & Persistence**: React Context API with LocalStorage synchronization

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or bun

### Installation
```bash
# Clone the repository
git clone https://github.com/ayeshakhawaja581-lab/my--first--repository.git

# Navigate to project directory
cd my--first--repository

# Install dependencies
npm install

# Start development server
npm run dev
```

Open your browser at `http://localhost:3000`.
